# Contributing

1. Create a feature branch from `develop`.
2. Keep changes scoped to one feature or fix.
3. Follow module dependency rules.
4. Add unit/integration/UI tests as applicable.
5. Update documentation and feature matrix.
6. Run `gradle test`, `gradle lint`, and `gradle assembleDebug`.
7. Open a pull request with behavior, test evidence, limitations, and screenshots where relevant.

Commit convention:
- `feat(scope): description`
- `fix(scope): description`
- `test(scope): description`
- `docs(scope): description`
- `refactor(scope): description`
